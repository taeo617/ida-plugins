# NPatch — 라이노 N각형 구멍 채우기 플러그인 (v0.3)

구멍 둘레의 엣지나 커브를 고르면, 그 구멍을 **매끈한 NURBS 서피스 한 장**으로 채워 주는 Rhino 8 플러그인입니다.
연속성은 엣지마다 G0, G1, G2 중에서 고를 수 있습니다.

## 명령어

### `NPatch` — 실시간 패널

1. 구멍 둘레의 엣지나 커브를 선택합니다. 3개 이상이거나, 닫힌 커브 1개면 됩니다. 끝나면 Enter를 누릅니다.
   - **엣지 하나를 더블클릭하면 구멍 둘레 전체가 한 번에 선택됩니다.** 여러 장의 면으로 둘러싸인 구멍도 됩니다.
   - 이미 고른 엣지를 다시 한 번 클릭하면 선택에서 빠집니다.
2. 패치가 지나가야 할 내부 커브나 점을 선택합니다. 없으면 Enter를 누릅니다.
3. 패널에서 설정을 바꾸면 백그라운드에서 다시 계산하고, 뷰포트 미리보기가 바로 갱신됩니다.

| 패널 항목 | 내용 |
|---|---|
| 상단 배너 | 전체 판정(✓/⚠)과 계산 시간 |
| ① 옆 면과 얼마나 매끄럽게 이을까요? | G0 = 붙이기만, G1 = 꺾이지 않게, G2 = 휘어진 정도까지 똑같이. `모든 엣지` 버튼이나 엣지별 드롭다운으로 고릅니다. 엣지마다 틈·각도·곡률 차가 표시되고, 허용오차 안이면 초록, 넘으면 빨강입니다 |
| ② 새 면의 모양 | 매끈함 단계(차수 3 보통 / 5 더 매끈), 면을 나누는 칸 수(스팬, 조절점 개수 표시), 경계가 안 맞으면 칸 수 자동으로 늘리기, 볼록하게↔팽팽하게 슬라이더 |
| ③ 확인용 표시 | 화면에만 보이고 결과 면은 바뀌지 않습니다. 제브라는 라이노 Zebra 명령과 같은 셰이더와 같은 설정(방향, 줄 굵기 7단계, 줄 색)을 그대로 씁니다. 그 밖에 곡률 콤(분홍 = 새 면, 파랑 = 옆 면, 길이 조절), 엣지 라벨, 조절점 |
| 하단 | 옆 면들과 하나로 합치기(구멍을 둘러싼 면이 여러 개여도 전부 폴리서피스 하나로 합침. 경계를 커브로 고르면 꺼짐), 취소/적용 |

패널의 모든 설정(연속성, 차수, 칸 수, 콤 길이 등)은 바꾸는 즉시 저장되어 다음 실행 때 그대로 열립니다.
제브라 방향·굵기·색은 라이노 자체 Zebra 설정이라, Zebra 명령에서 바꾸면 NPatch에도 그대로 적용되고 그 반대도 마찬가지입니다.
패널은 라이노의 라이트/다크 모드를 따라갑니다. 패널 모습은 `dev/panel_preview.png`에서 볼 수 있습니다.

**뷰포트 조작**
- 뷰포트의 엣지 라벨(예: `E2 G2 0.4%`)을 클릭하면 그 엣지의 연속성이 G0 → G1 → G2 순서로 바뀝니다.
- 패널에서 엣지 드롭다운을 누르면 해당 엣지가 뷰포트에서 굵게 강조됩니다.
- 패널이 떠 있는 동안에도 뷰포트를 돌리고 확대할 수 있습니다.

### `NPatchFill` — 패널 없는 버전

스크립트나 매크로에서 쓰기 좋은 명령어입니다. 예: `_NPatchFill _Continuity=G2 _Enter`

## 면 만드는 방식 (자동 선택)

| 구멍 | 방식 | 특징 |
|---|---|---|
| 4변 (모서리가 4개, 매끄럽게 이어진 엣지 여러 개는 한 변으로 침) | **트림 없는 4변 면** | 경계 커브가 그대로 면의 테두리. 아이소커브가 경계를 따라가고, G1/G2는 테두리 안쪽 조절점 줄로 맞춤 |
| 3변, 5–8변 | **트림 없는 4변 조각** (5·6변은 보통 2조각) 또는 트림한 면 | 아래 설명 참고 |
| 그 밖 (내부 점·커브가 있을 때 등) | 트림한 면 | 큰 면을 만든 뒤 경계로 잘라냄 |

패널 위쪽에 어떤 방식으로 만들었는지 표시됩니다(예: `트림 없는 4변 조각 6개`). 4변 방식이 실패하면(면이 접히는 등) 자동으로 트림 방식으로 바뀝니다.

**4변이 아닌 구멍 나누기**
1. 먼저 구멍 전체를 트림 방식으로 풀어 **안내 면**으로 씁니다.
2. 안내 면 위에 자르는 커브를 그려 구멍을 4변 영역으로 나눕니다. 나누는 방법은 세 가지이고, 해당하는 것을 모두 만들어 본 뒤 가장 좋은 것을 씁니다(조각이 적은 쪽 우선).
   - **5변: 한 번 자르기 → 2조각.** 가장 완만한 코너에서 맞은편 변의 가장 가까운 점까지 자릅니다. 길고 가는 띠 모양, 한 코너만 완만한 구멍에 가장 잘 맞습니다.
   - **6변: 마주 보는 코너끼리 한 번 자르기 → 2조각.**
   - **3–8변: 각 변의 가운데에서 중심까지 → 코너마다 1조각.**
3. 조각마다 트림 없는 4변 면을 만듭니다. 구멍 쪽 변은 옆 면에 맞춥니다.
   - **2조각(한 번 자르기)은 두 조각을 한 번에 같이 풉니다.** 자른 변은 양 끝 두 제어점(위치와 방향)만 자르는 커브에 두고 나머지는 풀어 둡니다. 두 조각은 그 변을 따라 위치·접선(C1)·곡률(C2)이 같도록 묶여 한 장의 면처럼 휘고, 이음 위치도 가장 매끄러운 자리로 스스로 옮겨 갑니다. 안내 면의 모양(특히 이음 옆 곡률 능선)이 조각으로 옮겨 오지 않습니다.
   - 3조각 이상(부채꼴)은 자른 변을 처음엔 안내 면에, 그다음엔 옆 조각 자체에 몇 번 다시 맞춥니다.
   - 자르는 커브의 끝은 구멍 엣지의 옆 면(또는 코너에서 가능한 유일한 법선)에 정확히 맞춥니다.
   - 자른 변을 따라 두 조각은 같은 스팬 수를 씁니다.
4. 엣지가 허용오차를 넘으면 스팬을 늘려 다시 풉니다(간격·각도·곡률을 모두 봄).
5. 조각을 하나의 폴리서피스로 붙입니다.

결과는 모든 엣지가 허용오차 안에 들어오면 바로 씁니다. 아니면 트림 면을 포함한 후보 중 허용오차를 가장 적게 넘는 것을 씁니다.
코너에서는 두 옆 면의 곡률이 서로 다른 경우가 많아서, G2 조건을 코너에서 0으로 두고 엣지 길이의 15% 지점까지 부드럽게 키웁니다. 이렇게 해서 코너 근처가 부풀지 않게 합니다.
옆 면끼리 코너에서 이미 각도가 어긋나 있으면(입력 모델 자체가 G1이 아닌 코너), 그 코너 근처에서는 G1 조건도 같은 방식으로 풀어 줍니다. 어긋남은 판정에서 따로 보는 "코너 구간"이 흡수합니다. 조각 이음도 양 끝 12%는 코너 구간으로 따로 표시합니다.
엣지 접선은 부드러운 해를 먼저 구한 뒤, 엣지 바로 안쪽 제어점 한 줄만 최소로 움직여 정확히 맞추고 고정한 다음 안쪽을 다시 풉니다. 가중치를 세게 키우는 방식과 달리 엣지 옆에 하이라이트 띠가 생기지 않습니다.
굽힘 에너지는 스팬마다 가우스 4점으로 정확히 적분합니다. 칸 가운데만 샘플링하면 엣지나 이음 바로 옆의 얇은 휨이 거의 벌점을 받지 않아 가는 하이라이트 선으로 보였습니다.

## 원리

1. 경계를 샘플링하고, 엣지마다 이웃 면의 법선과 곡률(제2기본형식)을 구합니다.
2. 경계에 가장 잘 맞는 평면 위에 정사각형 NURBS 패치를 깝니다.
3. 최소제곱으로 제어점을 풉니다.
   - 굽힘 에너지(얇은 판)에 팽팽함 정도만큼 막 에너지를 더한 값을 최소화합니다.
   - 경계에서 위치(G0)가 일치하도록 합니다.
   - 경계에서 n·Su = n·Sv = 0, 즉 이웃 면과 접하도록(G1) 합니다.
   - 경계에서 n·Suu, n·Suv, n·Svv가 이웃 면의 제2기본형식과 같도록(G2) 합니다. 이 조건은 비선형이라 직전 해를 기준으로 선형화한 뒤 3번 반복해서 풉니다.
4. 밴드 행렬 Cholesky로 풀고, 경계 루프로 트림합니다.

```powershell
dotnet build NPatch.csproj -c Release
```

`bin/Release/net7.0/NPatch.rhp`를 라이노 창에 끌어다 놓으면 설치됩니다.
라이노가 플러그인을 쥐고 있으면 빌드가 실패하니, 다시 빌드하기 전에 라이노를 닫아 주세요.

## 파일

- `src/NSidedFill.cs`: 계산(G0/G1/G2, 엣지별 측정값), 방식 자동 선택
- `src/QuadFill.cs`: 4변 구멍용 트림 없는 면, 여러 조각을 한 행렬로 같이 푸는 부분(Sys, SolveJoint)
- `src/SplitFill.cs`: 4변이 아닌 구멍을 4변 조각으로 나눠 채우기
- `src/PatchSession.cs`: 백그라운드 계산, 엣지 순서 정렬
- `src/PatchConduit.cs`: 뷰포트 미리보기, 제브라, 곡률 콤, 라벨, 제어점
- `src/PatchDialog.cs`: 실시간 패널과 설정 저장
- `src/Ui.cs`: 패널 디자인 컴포넌트(세그먼트 버튼, 토글, 슬라이더, 카드)
- `src/BoundaryPicker.cs`: 경계 선택(더블클릭 = 구멍 둘레 전체)
- `src/NPatchCommand.cs`, `src/NPatchFillCommand.cs`: 명령어
- `dev/`: SDK 없이 라이노 안에서 계산을 테스트하는 도구와 테스트 모델
